# 👟 Inventario de Zapatos - CRUD API

Este proyecto es una **API REST** construida con **Spring Boot** que permite gestionar un inventario de productos (zapatos).  
Incluye operaciones básicas de **CRUD**: crear, leer, actualizar y eliminar productos.

## 🛠️ Tecnologías utilizadas
- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL 
- Lombok
